BlinkMore should read as a quiet optical instrument built from aperture geometry, measured time marks and a small semantic palette. Keep the eight blue points as the only brand stamp. Use the system face with tabular figures, reserve semibold for the main value and section label, and keep supporting labels regular at the existing 14 px visible text floor. Do not use a generic icon pack or stock line glyphs for content. Build the activity and eye visuals as custom SVG from measured data; retain native system symbols only for standard utility controls. Set the dark field to ink #0D151A, flat panel #142128, inset #1B2A30, edge #2D3B40, primary text #E5ECE8 and secondary text #A2B1AF. Set light parity to chalk #F4F5F2, white #FFFFFF, inset #EEF2EF, edge #D5DEDA, primary text #1C2928 and secondary text #62716D. Preserve meaning across themes with brand blue #2785E6, blink rose #EF79B2, tracked mint #72CE97, active day cyan #5DC7CB, geometry iris #B29BEA and exercise amber #E8A967. In light mode use the same hues at readable darker values: blue #0C66BD, rose #B33E76, mint #347C4E, cyan #177780, iris #6D55AE and amber #935D16. Shape and labels also distinguish the channels, so color never carries meaning alone.

Keep all surfaces and visualizations flat. Gradient coordinates, color stops and alpha are absent by design; fills use solid sRGB values. The native window owns the only elevation shadow. Data sections use a single structural edge and tonal fill, with no card shadows, nested inset shadows, blurred backplates or per card glow. Shadow state never animates. Hover and selection update fill and edge immediately; focus uses a visible outline. Motion belongs only to a changing measurement, an eyelid state or a guided timer. Those transitions use one short ease, around 160 ms, and become static under reduced motion.

On the everyday Activity screen, keep the eight point mark, date and one compact tracking status in a shallow header. Let one custom SVG field carry the page in two linked bands. The upper band shows seven actual daily blink rates as aperture marks on a shared baseline, with today accented and days without enough tracked time shown as open marks. Beside it, today’s blink count is the strongest number and the three personal goals appear as thin progress strokes instead of nested rings. The lower band is the eye rhythm: sixty one second positions show tracked coverage and confirmed blink events, making time and cadence visible without another card. Recent rate, daily rate and personal baseline sit together as small readouts along the field. Milestones become quiet ticks on the history line, not separate medal cards. One short label names each visual; definitions and threshold details remain available on expansion. The dark 2.2 screenshot currently stacks three rings, four metric cards, a milestone shelf and more charts below the fold, so this composition makes the recorded activity the first thing the eye understands.

Draw both calibrated eyelid contours with clean custom SVG curves in the same visual frame and scale each to its own open baseline. The paired curves and their center difference reveal movement directly; the existing landmarks, confidence and sample age remain available as compact values nearby. Replace the decorative grid with a few quiet axis ticks. Preserve stroke visibility with a safe inset of at least the full stroke width plus four viewBox units, use non scaling strokes, and keep focus outlines and endpoint markers outside any plot clip. Never crop an eyelid, data mark or control at a rounded card edge. The light screenshot already shows useful real contours, but surrounds them with several text heavy boxes; let the live pair become the illustration and disclose the math only when asked.

The native statistics owner already keeps one second coverage and blink bins in memory, but the page does not receive them yet. Pass only that bounded in memory window to the rhythm SVG before drawing its sixty positions; until then show the recent rate as an aggregate mark and no invented pulse history. The paired eye illustration can use the live contours immediately.

When someone starts an optional eye reset, move into one focused exercise surface with one custom SVG scene instead of opening another dashboard card. Use a paired aperture and a simple guide shape that changes with the current step; a thin progress path shows elapsed time, while one brief instruction names the step. Start, pause, resume and skip remain visible as plain controls. Pause freezes both the path and illustration, resume continues from that exact point, and completion settles the drawing into a still state without a score or reward animation. The artwork gives the user the cue visually, while accessible step text and status preserve the full instruction for assistive technology.

The product visual language is specific to BlinkMore’s actual measurements and the blue eight point mark. The Dolphin reference is absent from the available BlinkMore screenshots, UI and planning material, so this direction assigns it no silhouette, color or identity.
