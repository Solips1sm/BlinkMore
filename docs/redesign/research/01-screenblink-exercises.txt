At pinned ScreenBlink commit 8b801ce1d43a285938f5fb07ca8bed7a20231080, the exercise inventory is four rotating text prompts: closed eye circles for ten seconds then reverse direction, closed eye up and down five times then left and right five times, a deep breath and a few natural yawns, and looking at something twenty feet away for twenty seconds. Only the first and last specify a duration; the first does not specify how long to reverse, the second says “slowly” without a cadence, and the yawn prompt has no count. The README only claims eye exercise reminders. [Prompt list](https://github.com/katunli/ScreenBlink/blob/8b801ce1d43a285938f5fb07ca8bed7a20231080/public/popup-renderer.js#L44-L62) [README](https://github.com/katunli/ScreenBlink/blob/8b801ce1d43a285938f5fb07ca8bed7a20231080/README.md#L3-L11)

The implementation is a reminder shell, not a guided exercise player. It selects one prompt per popup, advances a localStorage index as soon as the popup initializes, and offers Skip or Snooze. The default reminder interval is twenty minutes, configurable from five to sixty; the scheduler checks once a minute, resets its clock at app start, and closes an unanswered popup after thirty seconds. Snooze is five minutes. The exercise card has static text and buttons; its CSS only animates button hover state. The live marketing site currently promises a Pomodoro eye exercise feature and says it automatically implements the 20-20-20 rule by monitoring screen time. The pinned source instead times from app start or the last prompt and rotates four cards, so the twenty foot prompt appears once per four reminders at the default interval. Treat the prevention and treatment language on the marketing page as product copy, not an effect established by this code. [Live ScreenBlink claims](https://www.screenblink.org/)

For BlinkMore, keep two optional, nonclinical resets. A far look asks the user to choose a real distant object for twenty seconds; a custom inline SVG horizon and sun can animate a quiet countdown, then let the user mark it done. A short natural blink reset can let ordinary comfortable blinks light small SVG petals, with no pace or required count. Timers can verify elapsed time for either prompt and can animate a breathing cue if desired. The camera can count confident bilateral eyelid events if the Rust eyelid core exposes them, but it cannot establish that the object was twenty feet away, that gaze reached it, or that the user breathed or felt better. ScreenBlink’s detector accepts blink durations from 0.1 to 0.6 seconds and reports eyelid events; the source has no gaze tracking. Avoid carrying over eye rolls, closed eye gaze drills, and yawns because they are untimed or unobservable in this design.
